# Samyo Prospection for Claude Code

LinkedIn prospecting run by an AI agent, from Claude Code. [Samyo Prospection](https://samyo.fr) reads your website, works out who to contact and what to say, invites and follows up on LinkedIn within conservative limits, and hands over as soon as a prospect is interested.

## Install

```
/plugin marketplace add dibrilou45/samyo-claude-plugins
/plugin install samyo-prospection@samyo
```

## What you get

- **`samyo-decouverte`** (no account): prepare your LinkedIn prospecting strategy from your website (target job titles, offer, goal, tone, message sequence), then open the link to review it and launch with 10 free credits, no credit card.
- **`samyo`** (your Samyo account, OAuth through `/mcp`): campaign summary, prospects, messages to approve, strategy, pace, pause and launch. Every action is previewed; Claude only runs it after you say yes.
- **Skill `prospection-linkedin`**: tells Claude when to use Samyo and how, always asking before acting.

Ask for example: "Prepare my LinkedIn prospecting from my website", "Which prospects are interested this week?", "Pause my campaign".
